# JioNLP 许可证例外工程决策

日期：2026-08-28

用户选择继续采用 JioNLP sidecar 路径。该选择授权工程实现与验证继续进行，
但不等同于项目法务或治理层已经批准许可证例外。

已核实的依赖事实：JioNLP 1.5.29 的传递依赖包含 jiojio（GPLv3）和 certifi
（MPL 2.0）。因此：

- 生产发布前必须取得书面许可证例外或替代分发意见；
- pip-licenses 门禁保持失败状态，不得把这些许可证加入 Apache-2.0 兼容白名单；
- 本分支可以继续做本地功能、测试和容器验证，但不得据此声称可发布或可部署；
- 若治理层不批准例外，必须回到已固化的 120 行黄金语料，替换 parser 内核并重新资格验证。
