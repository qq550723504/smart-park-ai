脱敏运行 `a9a7be3c-b692-4ffd-a688-768fa93a896b` 最终为 `COMPLETED`：

PR #79 阶段验收已接受这条在线成功证据。本轮保留运行、窗口、楼宇过滤和结果依据，不将其降级为“从未成功”，也不重复运行来替换已接受记录。

## AI 助手

- 顶部入口可打开客户抽屉，不嵌入内部客服控制台。
- 推荐问题和页面上下文只写入草稿；浏览器核对草稿后消息数仍为 0。
- 停车问题通过现有客服会话 API 返回在线回答与“访客停车指南”来源。
- 另一真实回答触发知识不足边界时，页面显示客服工单 `CS-0001`、等待客服接入，并明确“不表示问题已经解决”。
- 关闭抽屉后焦点回到“AI 助手”；跨页重开保留会话与草稿。
- 首次会话和已有会话回复遇到响应丢失时，原问题、请求入口、目标会话和幂等键保持绑定；修改后的问题不能复用旧身份。
- 写请求进行中或结果未确认时，“重开导览”被阻止并重新打开助手关联；取得结果后才允许清理前端状态。
- 显式重开后，首页自身选择从 B2 回到登记的初始楼宇 B1；旧 B2 证据晚到不会恢复旧选择。后台工单、报告和运行没有删除。
