# Issue #73 客户演示能力映射

## 范围

本次只补客户 AI 助手入口、四页串联、演示重开和在线 AI 验收。四个页面继续由同一个 `CustomerShell` 承载；报告、告警工作流、工单、客服会话和运营分析均复用现有接口，没有新增第二套页面、Agent 后端、报告平台、通知、调度或持久化。

| 客户动作 | 实现来源 | 本次处理 | 能力边界 |
| --- | --- | --- | --- |
| 园区总览选择楼宇 | `ParkOverview` 与运营事实接口 | 直接复用 | 模拟业务数据，不冒充生产遥测 |
| 查看运营分析 | `EnergyAnalysis` 与现有分析 API | 复用同一楼宇和时间窗；补在线结构化时间证据兼容 | 只有显式点击才运行模型；失败保留既有事实 |
| 人工确认并建单 | #71 现有告警工作流 | 直接复用，保持实际审批与幂等回执 | 建单不等于问题解决；无合法告警标识时禁用 |
| 阅读与下载报告 | #77/#78 现有报告接口和快照状态 | 只增加从工单到报告的连续入口 | 不声称当前工单已自动写入历史报告 |
| 客户 AI 助手 | `CustomerServiceConsole` 使用的客服会话 API | 新增客户抽屉外观，复用创建会话、继续会话、引用与客服工单回执 | 不显示模型、Prompt、工具日志或 Trace；上下文只填草稿，不自动发送 |
| 重开导览 | 客户前端本地状态 | 显式确认后清除选择、草稿和助手会话展示 | 不删除工单、报告、运行或共享演示数据 |

## 在线分析契约修复

客户分析页传递精确 UTC 区间。确定性时间解析器把完整区间作为一个原子时间证据，在线模型则按既有提示逐字返回两个端点。原校验错误地把两种等价表示视为歧义，导致运行停在 `understandQuestion`。

修复只接受以下严格情形：模型返回的两个时间片段必须同时、逐字、逐位置对应同一个已由确定性解析器确认的 UTC 原子区间端点。只返回一个端点、普通日期的嵌套片段、越界片段或其他不一致仍失败关闭。总结提示同时与既有事实校验器对齐，禁止复述日期数字或生成趋势、原因和定性判断。

## 明确不做

- 不新增通用模型网关、客服后端、报告后端、消息通知、邮件、定时任务或回放平台。
- 不删除或重置本地演示环境中的后台数据。
- 不把演示 Compose 数据描述为真实园区生产数据。
- 不关闭总任务 #68；#73 PR 合并与部署均留给后续验收授权。
