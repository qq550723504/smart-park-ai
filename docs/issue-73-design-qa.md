# Issue #73 客户四页视觉 QA

## 对照基线

仓库与 Issue #68/#73 目前仍没有 `smart-park-ai-approved-designs.zip` 或四张 1672×941 原图。因此本轮不能声称完成了像素级原图对照。视觉检查采用 #68 已登记的构图、颜色和信息层级要求，以及 #69—#72 已交付页面作为统一基线；PR 验收时仍需由持有原图的评审者完成最终逐图对照。

## 已核对项

| 项目 | 结果 |
| --- | --- |
| 客户外壳 | 四页持续只有一个 `CustomerShell`、一个顶部导航和一个横幅容器 |
| 导航状态 | 园区总览、运营分析、事件与工单、运营报告使用同一选中样式；AI 助手使用独立展开状态 |
| 配色与卡片 | 延续浅蓝白背景、蓝绿强调、深蓝标题、圆角白卡和轻阴影 |
| 字体 | 继续使用客户界面的 Inter、PingFang SC、Microsoft YaHei 字体栈 |
| 文案 | 客服来源标题本地化；不展示模型名、Prompt、Trace、SQL 或内部错误 |
| 状态 | 文字与图标共同表达，不只依赖颜色；建单、转人工和报告快照均显示业务边界 |
| 助手面板 | 固定右侧抽屉，主页面加遮罩但不卸载；桌面和 1366 视口均无横向溢出 |
| 长内容 | 报告正文保持页面纵向滚动；助手消息区独立滚动，不与主页面争抢横向空间 |

## 保留差异

- 页面数据来自同一演示事实源，不复制原图中的示例比例、日期或楼栋数字。
- 报告下载只显示后端现有 Markdown，不增加原图可能出现但后端不支持的 PDF、分享或发送。
- 助手采用右侧抽屉，不新增未经确认的第五个全屏页面。
- 内部预检、模型配置、执行轨迹和能力矩阵不常驻客户页面。
